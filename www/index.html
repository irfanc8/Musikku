Tentang Musikku

Musikku adalah pemutar musik gratis untuk iPhone. Bisa memutar lagu full (bukan cuplikan 30 detik) dari arsip musik bebas, mengunduhnya untuk didengar offline, dan memutar file musik dari perangkatmu.

Sumber lagu online

Katalog online berasal dari Internet Archive (archive.org) — jutaan rekaman musik bebas, Creative Commons, dan rekaman live. Lagu pop arus utama yang masih berhak cipta tidak tersedia gratis di sini; untuk lagu seperti itu, gunakan tombol Impor File dan putar koleksimu sendiri.

Offline

  • Unduh — tekan tombol unduh pada sebuah lagu. Lagu tersimpan di perangkat dan tetap bisa diputar saat tidak ada internet.
  • File Saya — impor file MP3/M4A/OGG dari perangkatmu.

Privasi

Semua data (favorit, unduhan, file, riwayat) tersimpan hanya di perangkatmu. Tidak ada akun, tidak ada pelacakan.
